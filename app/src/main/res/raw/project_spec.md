溯澜录 项目说明书

1. 项目定位
“溯澜录”面向水生生物实验室与野外采样场景，提供从图片采集、物种检索到报告导出的完整闭环。强调本地优先存储与可自定义路径，确保科研照片不混入系统相册。

2. 核心目标
- 本地优先：所有图片先落地到 App 私有路径或自定义路径，优先保证本地可用。
- 路径可控：支持自定义存储路径并自动 `.nomedia` 隔离，系统相册不可见。
- 统一 UI：全局遵循首页风格与配色，保持一致的视觉语言。
- 高效导出：一键导出图片 ZIP 与鉴定报告 Word，支持导出质量调节。
- 完整物种库：内置物种名录，支持四大类与中文/拉丁名检索。

3. 技术架构
- 开发语言：Kotlin
- UI 框架：Jetpack Compose
- 本地数据：JSON 状态存储（LocalAppStore） + 文件系统
- 物种库：内置 JSON 资源 + Excel 导入
- 图片处理：Coil（预览）+ CameraX Extensions（HDR/夜景/自动增强）
- 文档导出：Apache POI（Word 报告）
- 云端扩展：预留配置入口（占位）

4. 功能模块
- 首页：入口引导与最近数据集。
- 数据集管理：创建与列表管理。
- 相机连拍：CameraX 连续拍照，本地保存并可立即关联物种，支持画质增强模式。
- 图库：本地导入、列表/网格预览、检索筛选、全屏浏览、缩放/滑动查看、返回顶部、勾选导出与文件夹直出。
- 分类库：搜索、导入/编辑与可展开的思维导图浏览。
- 数据集备份：本地备份、系统分享与导入恢复。
- 设置：存储路径、相册保存开关、导出质量、相机画质增强、缓存清理、更新日志。

5. 存储策略
- App 私有路径：默认路径，系统相册不可见。
- 自定义路径：用户选择目录，自动创建子目录与 `.nomedia`，保证相册隔离。
- 导出：支持用户选择保存路径（ZIP/Word）。

6. 迭代规范
- 必做流程：每次迭代必须同步更新更新日志、项目说明书、版本号。
- 历史归档：每次打包需保留历史 APK 存档。
